# yt-dlp GUI - محمل الفيديو الشامل
واجهة رسومية مستقلة لـ yt-dlp (1752 موقع) + إضافات متصفح
## المميزات
- تبويبات تحميل/إعدادات، تحميل متوازي 1-5، لا يعلق
- كوكيز تلقائي من المتصفح، حفظ التفضيلات
- ترجمة فقط، إيقاف/حذف فوري، سرعة وحجم
- خادم إضافة 127.0.0.1:8765 + إضافتان (متكاملة ومستقلة)
- Aparat/Meyon fallback عبر API
## التشغيل
`powershell
python app.py
`
## البناء
`powershell
powershell -ExecutionPolicy Bypass -File build_exe.ps1
`
